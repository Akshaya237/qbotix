QBOTIX ROVER - FRONTEND ONLY

Open index_FIXED.html in a browser to preview the interface.

This package contains only frontend assets (HTML, CSS, JavaScript, and panorama images). No Python backend or server dependencies are included.

Layout changes are intentionally limited to: applying the black/orange theme, setting the QBOTIX ROVER header title, and removing the IDMO dashboard. The existing GCS, ABEX, and RADO layouts are preserved. ABEX remains its own original layout; no IDMO panels are added to ABEX.

Live camera feeds, live telemetry, and sensor updates require the backend when you choose to integrate it later.
